03

Handling an unavailable model API.

I added a Gemini fallback chain that retries HTTP 429 and 503 errors. The reported request success rate is above 99%.

That measures whether the API request succeeds. It is not a measure of ticket correctness.

Metric

Request success and answer quality are different checks.
