Project notes / 02

Python, ChromaDB, BM25, BGE embeddings, Gemini API, FastAPI

01

Exact names matter.

Embeddings alone missed exact function names and error codes. I added BM25 keyword search alongside BGE embeddings, then merged the ranked results with Reciprocal Rank Fusion.

InputQuestions about a codebase
RetrievalBGE embeddings + BM25
FusionReciprocal Rank Fusion
Rerankerms-marco-MiniLM-L-6-v2
Storage / APIChromaDB, FastAPI, Gemini API
The tradeoff

Semantic similarity helps with meaning. Keyword retrieval preserves exact identifiers.

02

Retrieve, grade, retry.

I use HyDE for query expansion and a cross-encoder to rerank candidate passages. When relevance grading finds weak context, Corrective RAG rewrites the query and retries retrieval.

Read the diagram

The retry is conditional on retrieval quality.

03

Safety checks and evaluation.

I added PII redaction and prompt-injection checks at ingestion and inference. I evaluated answer faithfulness and citation accuracy with RAGAS and an LLM judge.

I have not supplied a numerical benchmark for this project here. The repository is the place to inspect the implementation and evaluation harness.
